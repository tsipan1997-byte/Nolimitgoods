# Автооновлення ставок (домашній ПК)

Ritchie Bros (захист Akamai) не пускає сервери й хмару, тому ставки збирає звичайний
домашній Windows-ноутбук з домашнім інтернетом.

- `setup.ps1` — одноразове налаштування: Git, Node, Chrome, розклад 08:00/14:00/20:00, без сну.
- `run.cmd` — що запускає Планувальник завдань.
- `update-bids.mjs` — збирає ставки з активних аукціонів Ritchie Bros, пише `lib/auction-prices.json`, пушить.
  `--dry` — зібрати й записати локально без коміту.
- Лог: `last-run.log` (і `task-output.log`). Обидва в .gitignore.

Якщо 0 ставок або «Access Denied» — нічого не пушиться, на сайті лишаються попередні ставки.
